# Philips N4520 Visualizer Handoff

This file records the current implementation state so the project can be resumed later without reconstructing the calibration history.

## Current Goal

The app is a photo-composited Philips N4520 reel-to-reel visualizer. It currently plays local MP3/FLAC files with a lightweight player, but most work has gone into making the transport visualization look like the real deck:

- reels rotate using tape-speed physics
- tape packs transfer from left to right
- VU needles respond to audio
- +3/+6 VU LEDs light from the same scale mapping as the needles
- pinch roller and tensioner rollers are animated as separate photo layers
- transport buttons use the physical button positions on the deck photo

## Important Files

- `index.html`: DOM layers for the deck, transport assets, VU needles, LEDs, controls, and audio element.
- `styles.css`: all visual placement, clipping, overlay sizing, and layer ordering.
- `app.js`: audio analyzer, transport state, reel/tape physics, VU scale mapping, and animation loop.
- `assets/n4520-deck-base-no-transport.png`: active deck base image. This came from `~/Pictures/deck/deck - no tensioner, pinch roller or reels.png`.
- `assets/reel-front-face.png`: active reel texture. This was reverted to the previous, less wobbly processed reel.
- `assets/reel-front-face-alpha1-backup.png`: saved fallback copy of the active reel texture before trying `reel alpha2.png`.
- `assets/pinch-roller.png`: cutout made from `~/Pictures/deck/pinch roller.png`.
- `assets/tensioner-roller-left.png`: cutout made from `~/Pictures/deck/tensioner roller L.png`; the right tensioner is mirrored in CSS.

## Asset Notes

The user-generated PNGs in `~/Pictures/deck` are RGB images with checkerboard-looking backgrounds, not true alpha PNGs. The active project assets were generated by converting the checkerboard background to alpha locally.

The current active reel image was restored from `assets/reel-front-face-alpha1-backup.png` because `reel alpha2.png` still showed visible wobble. Do not assume a normalized-looking reel source is rotationally stable; verify both outer radius and hub center.

The latest background image intentionally removes the pinch roller and tensioner rollers. Those are now composited separately:

- pinch roller body stays fixed
- only the pinch roller face layer rotates
- tensioners spring upward when the transport starts, overshoot slightly, then settle near the center of the slots

## Motion And Physics

Reel motion:

- maximum reel size: `10.5 in`
- full tape pack diameter: `9.35 in`
- empty visual pack diameter: `hubDiameterIn * 1.2`
- angular speed is derived from current tape pack diameter and selected IPS

The empty pack radius was expanded by 20% because the tape visually begins closer to the edge of the reel opening than to the physical hub.

VU meter mapping:

- displayed range is `-20 dB` to `+6 dB`
- full-scale audio peaks map to `+6 dB`
- the meter uses a piecewise `vuScale` table in `app.js`
- yellow LEDs are keyed to the red-zone start angle, not a separate guessed audio threshold

Pinch roller:

- DOM layer `#pinchRollerPhoto`
- fixed body image plus clipped `.pinch-roller-face`
- only the face rotates to avoid perspective wobble
- `.head-assembly-occluder` masks the top-left area so the engaged roller appears partially behind the head assembly

Tensioners:

- left asset is used directly
- right asset is mirrored with CSS
- `tensionerState` has spring lift, velocity, and randomized wobble
- movement follows the black slot arcs approximately, from bottom/rest to center/run with an upward kick

## Known Fragile Areas

- The tape path is still a hand-tuned SVG path. It follows the reel pack radius and tensioner positions, but it is not a true geometric wrap simulation around every guide.
- The pinch roller occluder is an approximate CSS shape and may need refinement after screenshot inspection.
- The active reel is still a photo cutout, not a true 3D mesh. It should look better than `alpha2`, but any wobble should be checked in motion after future asset changes.
- Several old reference assets remain in `assets/` but are not active.
